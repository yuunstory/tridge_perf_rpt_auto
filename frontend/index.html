🔗 구글 스프레드시트 양방향 연동 센터

구글 시트를 중앙 DB로 지정하면, 웹 입력 내용이 실시간 자동 적재되고, 구글 시트에서 수정한 최신 내용도 원클릭 동기화됩니다.

[1] 구글 스프레드시트 주소 (읽기 및 동기화용)

[2] 웹 폼 입력 ➔ 구글 시트 자동 적재 설정 (Apps Script Webhook)

웹 폼에서 입력 즉시 구글 시트에 자동으로 새 행이 생기게 하려면, 구글 시트의 [확장 프로그램 > Apps Script]에 코드를 넣고 발급받은 웹 앱 URL을 등록해 주세요.

📖 1분 만에 끝내는 구글 스프레드시트 양방향 연동 방법

  1. 1단계: 표준 템플릿 구글 드라이브에 올리기
    상단의 [표준 구글시트 템플릿 파일 받기] 클릭 ➔ 본인 구글 드라이브에 업로드 후 [Google 스프레드시트로 열기]를 클릭합니다.
  2. 2단계: 시트 공유 권한 설정 (부서원 접근 허용)
    우측 상단 [공유] 클릭 ➔ 사내 부서원들에게 편집 권한을 부여하거나 [링크가 있는 모든 사용자 - 뷰어/편집자]로 설정 후 주소창 링크를 위 [1]번에 입력합니다.
  3. 3단계: 실시간 자동 적재 활성화 (선택 사항)
    구글 시트 메뉴의 [확장 프로그램] ➔ [Apps Script]를 열고, 우측 상단의 [📋 Apps Script 연동 코드 복사] 내용을 붙여넣은 뒤 [배포 ➔ 새 배포 ➔ 웹 앱(액세스: 모든 사용자)]으로 배포한 URL을 위 [2]번에 입력하면 완벽하게 자동 연동됩니다.
