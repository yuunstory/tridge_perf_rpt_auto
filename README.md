# 📊 트릿지(Tridge) 성과보고서 자동화 시스템
> **부서별 사용 내역 실시간 취합 · 정량 ROI 자동 분석 · 경영진 보고용 워드(.docx) 원클릭 생성 플랫폼**

---

## 🌟 핵심 기능

1. **🔗 구글 스프레드시트(Google Sheets) 실시간 연동**
   * 각 부서(상품소싱, 해외수출, 원료매입 등) 실무자들이 사내 공유 구글 시트에 작성한 내용을 **URL 입력 한 번으로 실시간 동기화(Sync)**합니다.
   * 부서별 오입력을 방지하는 표준 구글 시트 양식(`xlsx`)을 원클릭으로 다운로드하여 구글 드라이브에 바로 업로드할 수 있습니다.
2. **📈 실시간 KPI 집계 및 시각화 대시보드**
   * 전사 재무 기여 추정액(원가절감 + 수출 파이프라인 합산), 리서치 절감 시간, 타깃 DB 확보 수, 솔루션 만족도를 자동 계산하여 즉시 시각화합니다.
3. **📄 경영진 보고용 워드 문서 (`.docx`) 원클릭 자동 생성**
   * 공식 표지(Cover Page), Executive Summary, 3대 핵심 비즈니스 성과(Top 3 Highlights), 전사 KPI 대시보드 표, 부서별 Deep Dive 카드, VOC 개선요청서, 종합 제언이 완비된 고품질 기업 워드 문서를 즉시 생성합니다.
4. **🤖 AI 기반 비즈니스 분석 엔진 내장**
   * Google Gemini API를 통한 실시간 고도화 분석 지원 (환경변수 `GEMINI_API_KEY` 설정 시).
   * API 키가 없어도 데이터 통계를 유기적으로 결합하여 전문 비즈니스 보고 문안을 완성하는 **자체 룰베이스 AI 엔진**이 내장되어 항상 정상 작동합니다.

## 📖 구글 스프레드시트 연동 방법

1. **표준 템플릿 준비**:
   * 웹 대시보드 사이드바의 `[📥 구글시트 취합 서식 받기]`를 클릭하여 엑셀 템플릿을 다운로드합니다.
   * 구글 드라이브(Google Drive)에 업로드 후 **[Google 스프레드시트로 열기]**를 실행합니다.
2. **시트 링크 공유 설정**:
   * 구글 시트 우측 상단 `[공유]` 클릭 ➔ `[일반 액세스: 링크가 있는 모든 사용자 - 뷰어]`로 설정합니다.
3. **대시보드에서 동기화**:
   * 대시보드의 `[🔗 구글 스프레드시트 연동]` 탭으로 이동하여 구글 시트 URL을 붙여넣고 `[🔄 실시간 데이터 동기화]` 버튼을 누릅니다.
4. **보고서 생성**:
   * 상단의 `[📥 워드(.docx) 보고서 생성]` 버튼을 누르면 정식 경영진 보고서가 즉시 다운로드됩니다.
